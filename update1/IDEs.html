Integrated Development Environment's

Below are a few links to some IDE's that may be useful; download and install the one you prefer. These IDE's come with their own strengths and weaknesses; however, Visual Studio Code is the focus of this site. This page assumes you already have a GitHub account and can sign in once Visual Studio Code is installed. You will also see how to change the visual appearence to better suit your preffence whether it is light mode, dark mode or any other choice from the default list. You can also create a custom theme using a .json file, but that is not a focus for beginners, though, the option is there. Feel free to look into it by searching on google or just go directly to the VS Code website and learn the entirty of the software there. Steps reguarding how to set up your ropsitory to push to your GitHub will be found on the GitHub Integration page.

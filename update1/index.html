Learn the setup

Welcome to the Coding Help Center where you learn how to set up coding software and other useful tools in the coding process. The goal is to ensure users have success in getting started with their coding journey. Not all users have the same skill set, whether that is setting up software or troubleshooting issues that arise. This site is geared towards the Windows OS, more specifically Windows 11, but that mean you will not have success. You can use this site as the starting point for finding solutions or a guide to tools that are available on multiple platforms.

This site is built to assist instructors and students by placing all information in a single source for the following:

  • Diagram Tools
  • Integrated Development Environment's (IDE's)
  • Setting up GitHub Integration with VS Code
  • Programming language setups
  • Reliable External Resources

During some of my coding courses, I noticed there was a recurring trend of time consuming troubleshooting and setup. I have taken it upon myself to make the process as smooth as possible while also including some known error resolutions without having to scour the internet. Even with AI, the answers can feel very vague or maybe they are scattered across multiple web pages. I encourage anyone using this site to bookmark any links you find useful, especially if you use them frequently.
